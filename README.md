# Mary Akanji Portfolio (19)

Create a modern, professional and responsive personal portfolio website for Mary Akanji. The website is for showcasing my education, Human Resources Management background, technical skills, soft skills, certifications, projects and work experience to potential employers.

Create these sections:

Home

About Me

Technical and Soft Skills

Projects

Education

Certifications

Work Experience

Contact

The design should be professional, clean and modern, suitable for someone applying for internships and entry-level employment opportunities.

Make the website responsive on desktop, tablet and mobile devices.

Include navigation links that smoothly take the user to each section.

Include project cards for at least three projects. Each project should have a project title, description, technologies/tools used and space for a project link.

Include a downloadable CV button.

Include contact information and links for GitHub and LinkedIn.

Use accessible typography, good spacing, professional animations and a clean professional colour scheme.

Do not invent qualifications, certifications, employment dates, projects or contact details. Use placeholders where information has not yet been provided.
